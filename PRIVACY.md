# Política de Privacidade / Privacy Policy

**Ollama Talk**\n
Última atualização: 7 de maio de 2026

## Português

O Ollama Talk não coleta, armazena ou compartilha dados pessoais dos usuários.

- A chave de API da Ollama Cloud é armazenada **localmente** no dispositivo (SharedPreferences) e nunca é enviada para nossos servidores.
- As conversas são armazenadas **localmente** no dispositivo, em arquivos JSON internos.
- O app se comunica diretamente com a API da Ollama Cloud via HTTPS. Nenhum dado passa por servidores intermediários nossos.
- Não utilizamos anúncios, trackers nem serviços de análise.
- O app não solicita permissões desnecessárias (apenas INTERNET e RECORD_AUDIO para funcionalidade de voz).

Para dúvidas, entre em contato via Liberapay: https://liberapay.com/gui.orioli

---

## English

Ollama Talk does not collect, store, or share any personal user data.

- The Ollama Cloud API key is stored **locally** on the device (SharedPreferences) and is never sent to our servers.
- Conversations are stored **locally** on the device, in internal JSON files.
- The app communicates directly with the Ollama Cloud API over HTTPS. No data passes through intermediate servers of ours.
- We do not use ads, trackers, or analytics services.
- The app does not request unnecessary permissions (only INTERNET and RECORD_AUDIO for voice input functionality).

For questions, contact via Liberapay: https://liberapay.com/gui.orioli
